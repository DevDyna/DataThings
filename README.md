# Numismatic Reforged Bounties mod
A mod addon based on [Bountiful](https://legacy.curseforge.com/minecraft/mc-mods/bountiful) that change many trades to use [Numismatic Overhaul Reforged](https://legacy.curseforge.com/minecraft/mc-mods/numismatic-overhaul-reforged) coins

It should support most of the others forks of Numismatic Reforged
